To set up another computer

  1. Make sure PowerShell 7 and Node.js are installed (the script tells you exactly what's missing and the winget
  command to fix it).
  2. Copy install.ps1 over and run:
  pwsh -NoProfile -ExecutionPolicy Bypass -File install.ps1
  3. Restart Claude Code, press Shift+Tab.

  No calibration needed: the 5h and 7d usage bars read live from widget_limits.json — Claude Code's own cache of
  the /usage data — so they match the /usage command exactly. ccusage (cost / $USAGE_CAP_USD) is only a fallback
  used when that cache is missing or stale; only then is it worth setting $USAGE_CAP_USD in
  ~/.claude/statusline_model.ps1 to  current_5h_cost / (usage_percent / 100).

  Status line layout:  Model  [effort]  <5h bar> %  <7d bar> %  <context> tokens
  Both bars turn amber at >=75% and red at >=90%.
